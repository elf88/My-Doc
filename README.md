# فیگـورا — Figora Studio 🖼️

سایت فروش و سفارش اختصاصی اکشن‌فیگورهای پرینت سه‌بعدی — با تم شیشه‌ای (Glassmorphism)،
کاملاً راست‌چین و فارسی.

## ساختار

```
├── index.html              ← صفحه‌ی اصلی (تک‌صفحه‌ای)
├── assets/
│   ├── css/style.css       ← تم شیشه‌ای، انیمیشن‌ها، ریسپانسیو
│   ├── js/app.js           ← فیلتر، جستجو، لایت‌باکس، فرم سفارش، تیلت ۳بعدی
│   └── img/                ← تصاویر فیگورها (JPG بهینه‌شده)
└── README.md
```

## اجرای محلی

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

## امکانات

- ✨ تم Glassmorphism: شیشه‌های مات، لبه‌ی نوری، حباب‌های نور متحرک، گِرِین
- 🛍️ ویترین محصولات با فیلتر دسته‌بندی + جستجوی زنده
- 🔍 لایت‌باکس نمایش بزرگ هر فیگور + دکمه‌ی «سفارش این فیگور»
- 🧾 فرم سفارش اختصاصی با اعتبارسنجی و اعلان (Toast)
- 🌐 فارسی، RTL، فونت وزیرمتن، اعداد فارسی
- 📱 کاملاً ریسپانسیو (موبایل / تبلت / دسکتاپ)
